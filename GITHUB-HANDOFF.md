# Repository maintenance

Repository: https://github.com/waay2tech/html-css-js-project-lab

Keep the existing episode slugs stable so subscriber links continue to work. Put a published video URL in its episode README only after the video exists. Run `npm test` and `npm run check` before source changes are merged. Preserve the root license, per-episode credits, archive notices, font notices and vendor licenses.

Use `npm start` for local preview. GitHub Pages can host the static root if a live deployment is configured later; the Node server is local-only. This initial source publication does not configure a live site or publish any new videos.

A public repository is visible to everyone with the link; there is no subscriber-only access gate.
